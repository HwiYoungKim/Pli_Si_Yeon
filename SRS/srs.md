## 1. 소개

### 1.3 정의·약어

| 용어 | 정의 |
| --- | --- |
| 현시연 임원 | 최상위 권한을 가진 회원. 동아리 일정·공지 등록, 소모임장 지정, 계정 정지·삭제, 게시글 삭제, 회원 개인정보 조회를 한다. 모든 소모임에 접근할 수 있다 |

| 소모임 일정 | 소모임 회원에게 보이는 일정 |
| 표시 단계 | 일정을 위에서 아래로 나열하는 순서의 5단계. 설정에서 순서를 바꾼다 |

| 임원 전용 코드 | 현시연 임원이 회원의 개인정보를 조회할 때 한 번 더 입력하는 코드. 로그인 비밀번호와 별개다 |
| 둘러보기 | 소모임 화면에서 가입하지 않은 소모임을 펼쳐 보는 동작. 누르기 전에는 미가입 소모임이 보이지 않는다 |

| 컴포넌트 | 한 페이지 안에서 같은 기능을 수행하고 서로의 값에 의존하는 UI의 묶음. 서로 의존하지 않는 기능은 같은 페이지에 있어도 다른 컴포넌트다 |
| 시트 | 화면 위로 올라와 겹쳐 보이는 층(하단 슬라이드) |

## 3. 상세 요구사항

### 3.1 외부 인터페이스

#### 3.1.1 화면 계층 구조

&#91;embedded content: 화면 계층 구조 · 6개 화면과 소모임 3종\]

화면의 층은 화살표로 정한다. 번호(①~⑥)는 화면을 만든 순서일 뿐 층의 깊이가 아니다.

- ① 로그인·회원가입 → ② 메인화면 → ③ 캘린더 → ④ 소모임 → ④-n-0 미가입 / ④-n-1 가입자 / ④-n-2 소모임장
- ③ 캘린더 → ⑤ 설정
- ③ 캘린더 → ⑥ 임원 설정 (현시연 임원에게만 보임)

④, ⑤, ⑥은 ③ 캘린더 바로 아래의 같은 층이다. n은 소모임을 만든 순서이고, 끝자리 0·1·2는 그 소모임에 대한 내 자격(미가입·가입자·소모임장)이다. 각 화면의 기능은 3.2에서 화면별로 정한다.

#### 3.1.2 스와이프 규칙

아래 그림은 탭 화면 사이를 좌우로 밀어 옮겨 다니는 빠른 이동이다. 화면의 층을 바꾸는 것이 아니라 같은 층의 탭을 오가는 지름길이며, 메인화면은 캘린더 위에서 이어진다. 화살표는 양방향이고 반대쪽 스와이프로 돌아온다.

&#91;embedded content: 탭 사이 스와이프 이동 · 5개 화면, 양방향\]

스와이프의 의미는 화면의 위치가 아니라 방향으로만 정한다. 한 화면에서 같은 방향의 스와이프에 두 가지 동작을 두지 않는다.

| 방향 | 어디서 | 동작 |
| --- | --- | --- |
| 좌우 | 탭 화면(소모임·캘린더·설정·임원 설정) 어디서든 | 인접한 탭으로 이동한다. 월 이동에는 쓰지 않는다 |
| 위로 | 메인화면의 일정 목록 밖 | 캘린더로 이동한다. 화면은 손가락을 따라 움직인다 |
| 위로 | 탭 화면 아래의 손잡이 | 하단 버튼 바를 연다. 손잡이를 누르는 것도 같다 |
| 아래로 | 캘린더 화면 | 메인화면으로 돌아간다 |
| 아래로 | 하단 버튼 바가 열려 있을 때 | 하단 버튼 바를 닫는다 |

### 3.2 기능 요구사항

기능 요구사항은 페이지 단위로 나누고, 같은 페이지 안에서는 컴포넌트 단위로 나눈다. 시트·팝업처럼 화면 위에 겹쳐 보이는 UI도 하나의 페이지로 본다. 같은 컴포넌트는 같은 기능을 수행하며 서로의 값을 필요로 하는 항목들이다. 컴포넌트는 화면에서의 위치 순서(위→아래, 왼쪽→오른쪽)대로 적는다.

화면의 층 구조는 3.1.1의 그림을 따른다. 번호(①~⑥)는 화면을 만든 순서이며 층이 아니므로, 3.2의 절 번호도 층과 무관하다.

#### 3.2.1 로그인·회원가입 화면

앱을 처음 열거나 로그아웃했을 때 보이는 화면이다. 아이디는 학번이다. 로그인 모드와 회원가입 모드가 있으며, 회원가입 모드에서 필수 권한과 선택 권한을 모두 받는다. 수집 항목 동의는 개인정보 보호법의 수집·이용 동의 취지(항목·목적·보유 기간·거부 권리 고지)를 따르려는 초안이며 법률 검토는 거치지 않았다.
